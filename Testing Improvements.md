## Notes

- The report is a pre-fix snapshot. The recent consultation-date parser change emits a warning rather than stopping the run, but still does not recognize this report's `DD/MM/YYYY` values; the planned normalization work remains necessary.
- Error counts are mutually exclusive by first failing stage. Rows that fail earlier cannot reveal whether later stages would also have failed.
- The report contains no structured count of successful polygon fallbacks, so retrieval observability requires additional telemetry rather than reclassification of the existing rows.
